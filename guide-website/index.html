THE PRINCIPLE

Do not try to know everything. Build a clear workflow, learn a small number of tools properly, and spend more time understanding buildings than collecting images of them.

FIRST YEAR IS NOT A TEST OF WHETHER YOU ALREADY KNOW HOW TO BE AN ARCHITECT.
It is where you build the habits that make every later project easier.
